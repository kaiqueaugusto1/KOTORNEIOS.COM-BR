# KO Torneios

Gerenciador de torneios em um único arquivo HTML: sorteio de duplas e grupos, fase de grupos, mata-mata, disputa de 3º lugar, final em melhor de 3 e liga com pontuação por colocação.

## Como usar
Abra o `index.html` no navegador. Os dados ficam salvos só no navegador de quem abre (modo local).

## Publicar no GitHub Pages
1. Crie um repositório e envie `index.html` e `README.md`.
2. Em Settings > Pages, escolha Branch `main` e pasta `/ (root)`.
3. O site fica em `https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/`.

## Aviso
Os três acessos (dono, criador e visualização) e o compartilhamento de dados só funcionam na versão publicada no Claude. Fora dele, o app roda em modo local.
